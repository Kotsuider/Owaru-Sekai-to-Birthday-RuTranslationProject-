# Руководство по сборке перевода

Данная инструкция описывает полный цикл: от структуры исходников перевода до компиляции байткода Majiro и упаковки готового архива `scenario.arc`.

---

## 1. Подготовка окружения и инструментов

Перед началом работы убедитесь, что у вас установлены и скачаны:
1. **GARbro** — для распаковки и упаковки игровых архивов `.arc`.
2. **Python 3.10+** с установленной библиотекой `openpyxl`:
   ```bash
   pip install openpyxl
   ```
3. Папка инструментария [MajiroTool](https://github.com/AtomCrafty/MajiroTools) 
4. Перенесите содежимое папки `ToMajiTools` в `MajiroTool.Cli.v1.0.26.1156`.
5. Распакуйте Owari.rar
6. Распакуйте оригинальный `scenario.arc` через GARbro в папку `st` и запустите `disassemble_st.bat`.


---

## 2. Структура проекта

```text
(корень проекта)/
├── MajiroTool.Cli.v1.0.26.1156/
│   ├── st/                        <-- Чистые оригиналы из scenario.arc (.mjo, .mjil, .mjres, .cfg и др.)
│   ├── Owari/                     <-- Исходники перевода
│   │   ├── Owari_*.md             <-- Сюжетные файлы сценариев в Markdown с переводом
│   │   └── Other_tr/              <-- Переведённые файлы .mail, .blog, .profile
│   ├── scenario/                  <-- Рабочая папка компиляции (формируется автоматически)
│   ├── scenario_tl/               <-- Итоговые скомпилированные файлы для игрового архива
│   ├── maji.exe                   <-- Компилятор/дизассемблер байткода Majiro
│   ├── mjres_tool.py              <-- Скрипт вставки перевода (.md/.xlsx -> .mjres)
│   ├── wrap_mjres.py              <-- Скрипт безопасного переноса длинных строк (>54 символов)
│   ├── sanitize_mjres.py          <-- Скрипт санитизации спецсимволов под кодировку CP932
│   ├── patch_furigana.py          <-- Скрипт отключения вывода японской фуриганы в байт-коде
│   ├── disassemble_st.bat         <-- Батник разового дизассемблирования чистых файлов в 'st'
│   └── build_translation.bat      <-- Главный скрипт автоматической сборки перевода
```


---

## 3. Сборка 

1. Перейдите в папку `MajiroTool.Cli.v1.0.26.1156`.
2. Запустите:
   ```cmd
   build_translation.bat
   ```
---

## 4. Упаковка архива `scenario.arc` в GARbro

1. Откройте **GARbro**.
2. Перейдите в папку:
   ```text
   MajiroTool.Cli.v1.0.26.1156\scenario_tl\
   ```
3. Выделите все файлы внутри папки (`Ctrl + A`).
4. В верхнем меню выберите **File → Create Archive...**
5. Укажите параметры архива:
   - **Archive type:** `Majiro (ARC)`
   - **Target name:** `scenario.arc`
6. Сохраните новый `scenario.arc` в корневую директорию игры, заменив старый (сохранив бэкап оригинала).
